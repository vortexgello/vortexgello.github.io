CubeSat Selfie Camera Boom

Custom Order

Deployable camera boom mechanism for capturing visual inspection data and "selfies" of the satellite in orbit.

Request Quote View Specs

The system uses stored strain energy to deploy a bistable composite or flexible polymer boom rolled compactly against the CubeSat.

Features an integrated flex PCB running along the boom length for the camera module, eliminating complex wire harnesses and reducing snag risks.

Camera Integration Off-the-shelf Module via Flex PCB
Deployment Method Stored Strain Energy
Form Factor Compatible with 1U+
Extended Length Up to 1.5 m
System Mass < 150g (w/ Camera)
Camera Resolution 5 MP (Typical)
Data Interface MIPI CSI-2 / USB
Power 3.3V / 150mW
Actuation Burn Wire Release
